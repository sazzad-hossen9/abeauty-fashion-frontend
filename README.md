# ABeauty & Fashion - Frontend

Modern, high-performance e-commerce frontend built with Next.js 14 (App Router), Tailwind CSS, and Lucide Icons. Designed for luxury beauty editorial aesthetics with dynamic MongoDB backend integration, responsive cart, wishlist, and seamless multilingual support (English & Bengali).

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Typography:** DM Sans, Bricolage Grotesque, Instrument Serif, Anek Bangla, Hind Siliguri
- **Icons:** Lucide React
- **State Management:** React Context (Cart, Wishlist, Auth, Language, Modals)
- **Backend API:** Node.js / Express / MongoDB

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
